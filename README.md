项目说明文档

一、 项目概述
Audio Journey Workstation 是一个自动化新闻聚合与语音合成工作站。系统基于 FastAPI 构建后端，纯 HTML/JavaScript/CSS 构建前端。其核心功能是整合 GPT-SoVITS 文本转语音接口，配合系统内的动态背景音乐混音逻辑，将网络抓取的长文本或输入文本自动转化为复合音频文件，并提供可视化的网页控制终端供用户下发任务。此外，系统通过集成 DeepSeek 大语言模型接口实现智能摘要，并具备全自动推送至外部静态展示网站（托管于 GitHub Pages）的完整流水线。

二、 核心特质
1. 前端交互界面：系统前端采用单文件原生架构编写，摒弃了常规的前端编译框架。前端实现了页面间的平滑切换、数据状态同步以及根据音频播放状态实时响应的可视化图表。
2. 自动化文本采集与大模型摘要：系统整合了具备数据清洗功能的脚本。脚本负责并发请求 RSS 新闻源，剔除网页杂质提取正文后，调用 DeepSeek API 将提取的长新闻浓缩为精准的引言摘要，并将“摘要+原文”以 JSON 格式结构化保存。
3. 动态混音算法：在语音合成结束后，系统会根据内部设定的权重比值自动匹配指定路径下的背景音乐，通过淡入淡出处理与目标语音进行重叠混流，生成最终的成品音频。
4. 外部橱窗站点与自动化发布：工作站外部挂载了一个用于对公众展示的独立静态网站（audio_site）。工作站完成全部数据（音频、图片、结构化文本）的组装后，系统脚本将自动执行本地 Git 提交操作并推送至远程代码库，实现无人值守的内容分发。
5. 推理控制模块：系统内部包含完整的推理参数调试平台，严格依据服务端 API 规范，支持用户对温度、随机种子、切分方式（cut0 - cut5）、语速等多项核心参数进行精确量化控制。

三、 目录结构说明
E:\pycode 目录下的核心文件与职责如下：
index.html: 内部控制台前端主视图文件，包含控制界面结构、样式定义与异步请求逻辑。
server.py: 内部控制台后端主控程序，负责启动 API 监听端口、转发路由以及扫描本地文件。
webui.py: 基于 Streamlit 构建的旧版备用控制台，功能与 FastAPI 版完全对等。
science.py 与 default copy.py: 自动化抓取新闻、调用 DeepSeek 提取摘要、执行 TTS 合成及音频后处理任务的核心 Python 脚本。
webui_submmit_request.py: 数据提交脚本，负责向远端或本地推理服务发送参数封包。
transfer_data.json: 本地环境下的数据中转文件。
auto.bat 与 auto_science.bat: 用于自动化启动工作流、驱动数据同步搬运（调用 sync_audio.py）以及向外执行自动 git push 的批处理流水线。
otp 目录: 存放工作站输出的最终合成原始音频文件。
text_data 目录: 存放由 DeepSeek 结构化产出的新闻摘要与对应原文的 JSON 文件。
selected_pictures 目录: 本地备选的高清背景图片资产库。

外部关联目录 (E:\pycode-serious\audio_site) 说明：
index.html: 向外展示的“橱窗”网站主页面，采用毛玻璃视差滚动与侧滑详情面板设计。
sync_audio.py: 数据中枢搬运调度程序。负责从工作目录拉取最新的合成音频、随机背景图以及相应的 JSON 文本数据，拼接封装并生成给外部网站调用的 data.js。

四、 运行指南
1. 启动准备：确认系统已安装依赖环境，如 fastapi、uvicorn、requests、newsplease、pydub 及对应的语音生成服务端环境。
2. 内部工作台启动：在 E:\pycode 目录下，使用命令行执行 python server.py 指令。打开本地浏览器输入 127.0.0.1:8000 进入操作界面；或执行 streamlit run webui.py 体验经典版工作台。
3. 外部展示网站发布：双击执行 auto.bat（世界新闻）或 auto_science.bat（科学新闻），全链路的新闻抓取、合成处理及网站数据刷新将自动在后台进行，并完成云端发布。

五、 维护与开发建议
1. 文本切分与参数修正：系统已全面对齐 GPT-SoVITS 的底层 API 设计。如需在 UI 拓展切分选项，务必参照 cut0（不切分）到 cut5（按所有标点符号切分）的官方文档规范，避免传入无效参数导致服务端异常。
2. 背景音乐概率调整：如需改变特定音频被选为背景音乐的概率，可前往对应的新闻合成 Python 脚本中修改 special_rules 字典及其对应的权重浮点数。
3. 展示网站样式调整：audio_site 前端基于纯原生 CSS 与 JS。若修改卡片排版或侧滑“阅读原文”面板逻辑，需要同时注意移动端媒体查询 (@media) 中的层级遮挡防范与宽度自适应响应。
